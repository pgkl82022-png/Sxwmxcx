# 业务服务

- service.js：服务端权限、库存、订单状态机、审批、审计。
- database.js：SQLite事务仓储与19个数据表（含schema_version）。
- files.js：管理员附件本地解析（Excel/Python、OCR/Tesseract），临时文件自动清理。

这是Node本地服务模块，尚未部署微信云函数。部署前需要在可信服务端将微信认证得到的openid映射为actor，查询门店角色，之后调用业务服务；绝不能把客户端传入的actor作为身份。数据库需更换为云事务实现；不能在每个无状态函数内重新初始化库存或共享本地文件。真实支付在得到授权后独立实现，不得把本地pay接口暴露成真实支付成功入口。
