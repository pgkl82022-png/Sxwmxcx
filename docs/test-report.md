## 已知工程限制与后续门槛

1. 本地单进程SQLite保存当前业务快照及投影，不具备云端多实例并发能力；没有真实微信身份、多租户或云备份。数据库用户/角色当前为演示值。
2. 原生小程序仅结构验证，缺少授权AppID及微信开发者工具/真机编译证据。
3. OCR需人工核对；语音录音转写、复杂票据自动结构化、交互合并、称重差额与临期批次尚待开发。
4. 图片授权证据是人工提交的审核依据，程序不能证明版权真实性；无授权检索服务时不自动找图。
5. 当前无付费AI供应商实现，默认本地规则；模型网关未做真实供应商调用和费用实测。隐私标记拦截不替代真实数据脱敏评估。
6. 未进行真实支付/退款、云部署、真实微信性能/弱网/体验版验证、正式审核。授权项和费用项集中见release-checklist.md，缺少凭据不在聊天索取。
7. 文件解析有大小、类型、超时与并发限制，仍需正式上传安全评估。SQLite恢复有完整性校验，生产恢复演练与完整删除政策尚未验收。
