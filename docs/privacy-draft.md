# 演示隐私说明与正式版本草稿

本地开发版仅用于虚构数据测试；不接入微信身份、不向外部模型发送顾客数据。下单收集收货人、联系电话、地址、配送时段，为模拟履约使用。商家可处理订单，分配骑手只获取配送所需订单和联系方式。数据库存储于本机.data目录，未设置公网访问。

本地会话一小时过期；联系信息清理工具支持终结90天前订单的去标识化与地址簿清理。清理前需备份并停止服务。真实经营必须进一步对自由文本、历史备份、日志、用户身份进行完整删除与保留策略管理。

正式版本尚需门店主体全称、联系方式、客服渠道、隐私负责人、使用的微信能力及第三方处理者清单、用户查阅/更正/删除途径、未成年人保护、信息安全与事件响应机制。没有这些内容时不可直接把本草稿用于正式审核。
