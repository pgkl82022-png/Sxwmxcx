# 青禾鲜选 · 生鲜超市

使用原生 HTML、CSS、JavaScript 和 Node.js 静态服务器的最小可运行版本，无第三方依赖。

## 运行

需要 Node.js 22 或更新版本，在仓库根目录执行：

```sh
npm start
```

浏览器访问 `http://localhost:3000`。使用 `PORT=3001 npm start` 可更换端口。

运行规则测试：

```sh
npm test
```

## 功能

- 保留 8 款商品展示与品牌页面，新增分类、多关键词搜索（名称、分类、标签、规格）联动、价格排序、结果计数与重置。
- 手机底部导航、安全区适配、44px 数量按钮与窄屏订单布局。
- 加入购物车、增减数量（单款最多 99）、移除、确认清空、已选数量提示、计算金额及免配送费差额。
- 配送费 6 元，商品满 59 元免配送费。
- 填写虚构配送信息、提交模拟订单、查看订单快照、接单前取消。
- 商家演示：全部订单、待处理数量、排除取消订单的模拟金额汇总、状态筛选及接单/备货/模拟发货/标记送达。
- 状态按“待接单 → 备货中 → 配送中 → 已完成”流转，阻止跳级和完成后修改。旧版待配送订单兼容显示为待接单。
- 购物车与订单使用 localStorage，刷新后保留，清除网站数据会删除记录。

此版本为前端演示，没有账户、后台数据库、真实库存、支付、配送或跨设备同步。请使用虚构配送信息。正式上线需由服务端校验价格和库存、保存订单并安全处理个人信息。

## 本阶段演示与验证

本次在 main 已有项目上增量修改，保持零运行时依赖、原有存储键和商品数据。
商家入口位于主导航，手机上位于底部。先从购物车提交一笔演示订单，再进入商家演示进行状态操作，回到“我的订单”可看到相同状态。刷新后记录保留；两个界面共享同一浏览器的数据，不是独立的商家后台或权限系统。

单元测试覆盖金额边界、非法数量、订单快照、输入校验、组合搜索、价格排序、状态流转、旧记录兼容与损坏记录过滤。

仓库包含可复现的 Chromium 端到端测试 `scripts/browser-check.mjs`。在单独终端 `npm start` 后，使用已安装的 Playwright 执行 `npm run test:browser`。默认 Chromium 路径为 `/usr/bin/chromium`，可用 `CHROMIUM_PATH` 覆盖；也可通过 `PLAYWRIGHT_MODULE` 指向外部安装的 Playwright ESM 入口，避免增加项目依赖。

浏览器测试覆盖 320、390、1280px 的分类、搜索、排序、加减购物车、刷新恢复、提交订单、商家履约、取消、清空购物车、横向溢出和 JavaScript 异常检查。所有操作仅使用本地服务与虚构数据，不接入真实支付、真实履约或公网部署。
