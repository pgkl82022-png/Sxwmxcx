# 青禾鲜选 · 一体化本地开发版

保留原生鲜网页演示，新增微信原生小程序、商家后台、骑手任务、服务端业务、SQLite数据库、批量导入、离线中文OCR及本地规则经营助手。**当前是模拟业务开发版，尚未完成微信云端接入和正式验收。**

Node.js 24 / Python 3，无 npm 运行时依赖。

```sh
npm test
DEMO_MODE=true npm start
```

- 旧演示：`http://127.0.0.1:3000/`
- 商家后台：`http://127.0.0.1:3000/admin/`
- 骑手工作台：`http://127.0.0.1:3000/rider/`
- 微信开发者工具导入仓库根目录，入口为 project.config.json；touristappid 占位，正式编译与真机预览需授权AppID。

演示模式仅本机使用虚构数据。模拟付款不扣款、模拟退款不操作资金。正常启动默认禁用免令牌演示登录，角色令牌通过环境变量注入，见 .env.example。

已覆盖商品分类搜索、购物车、地址、配送范围/时段、服务端校价/库存、起送/运费、幂等下单、超时释放、模拟支付、商家配货派单、缺货取消、骑手取送与异常、售后模拟审批。支持CSV/Excel/照片录入工作流、草稿校验与去重、图片候选授权审核、定价建议及日周月只读经营查询。

OCR需本机`tesseract`，运行 `bash scripts/setup-ocr.sh` 下载官方中文开源模型。识别结果存在错字，只能人工核对后整理成导入草稿；不会直接上架商品。
