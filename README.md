# 青禾鲜选 · 生鲜超市

使用原生 HTML、CSS、JavaScript 和 Node.js 静态服务器的最小可运行版本，无第三方依赖。

## 运行

需要 Node.js 22 或更新版本，在仓库根目录执行：

```sh
npm start
```

浏览器访问 `http://localhost:3000`。使用 `PORT=3001 npm start` 可更换端口。

运行规则测试：

```sh
npm test
```

## 功能

- 8 款商品展示、分类筛选、名称搜索与响应式布局。
- 加入购物车、增减数量（单款最多 99）、移除商品、计算金额。
- 配送费 6 元，商品满 59 元免配送费。
- 填写演示配送信息、提交订单、清空购物车、查看订单记录。
- 购物车与订单使用 localStorage，刷新后保留，清除网站数据会删除记录。

此版本为前端演示，没有账户、后台数据库、真实库存、支付、配送或跨设备同步。请使用虚构配送信息。正式上线需由服务端校验价格和库存、保存订单并安全处理个人信息。
